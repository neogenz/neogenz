## Agentic development

I don't use AI as glorified autocomplete. I design **agentic software workflows** that move from product intent to tested, reviewable code: research, architecture, implementation, testing, review, and delivery.

My focus is making that process repeatable through reusable skills, focused context, parallel specialist agents, and explicit quality gates — while keeping product judgment human.
